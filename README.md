# ✨ Gemini Pixel Desktop Pet

> Милый пиксельный компаньон Gemini, который живёт на вашем рабочем столе поверх всех окон! Создан на C# и WPF (.NET 10).

![Gemini Companion Preview](https://img.shields.io/badge/WPF-.NET%2010-blue?style=for-the-badge)
![Platform](https://img.shields.io/badge/Platform-Windows%2010%2F11-cyan?style=for-the-badge)

---

## 🌟 Возможности и Фичи

- **Автономный ИИ-поведение**:
  - Парит над рабочим столом с плавной синусоидальной анимацией.
  - Гуляет над панелью задач и по экрану, поворачиваясь в сторону движения.
  - Моргает, общается через пиксельные облачка реплик.
  - **Режим преследования курсора (Stalker)**: периодически крадётся за указателем мыши пользователя.

- **Спец-режимы и анимации**:
  - 👥 **Митоз (Деление)**: при быстром тройном клике Gemini делится на двух меньших питомцев!
  - 🧲 **Слияние**: собрать всех размноженных питомцев обратно в одного кликом из меню.
  - ❤️ **Любовный режим (Love Mode)**: розово-красная аура, сердечки вместо глаз и комплименты разработчику.
  - 🎉 **Супер-Звезда (Party Mode)**: золотое свечение, безумный танец Super Star.
  - 🕶️ **Крутые очки (Deal with it)**: пиксельные черные солнцезащитные очки с белым бликом.
  - 😴 **Спящий режим (Zzz)**: питомец закрывает глаза и сладко спит (пробуждается по клику).
  - 💫 **Вращение (Spin)**: раскрутка на 360° вокруг своей оси.
  - ⭐ **Кормление**: питомец радостно прыгает, когда вы даете ему звёздочку.

- **Кастомный киберпанк UI**:
  - Красивое контекстное меню в темной теме с неоновой подсветкой и закругленными углами.
  - Чистый Win32 Layered без мерцания и артефактов.

## 🛠️ Архитектура проекта

Код полностью структурирован по модулям:
```
GeminiScreenPet/
├── Animations/
│   └── SpriteFrames.cs       # 16x16 пиксельные матричные спрайты и цветовая палитра
├── Models/
│   └── PetState.cs           # Конечный автомат состояний (Idle, Walk, Love, Party, etc.)
├── Services/
│   ├── PixelRenderer.cs      # Быстрый пиксельный рендерер без перегрузки WPF
│   ├── SpeechLibrary.cs      # База фраз и реакций питомца
│   └── Win32Helper.cs        # Нативные вызовы Win32 API (Topmost, ToolWindow, Cursor)
├── MainWindow.xaml           # XAML-разметка, стили меню и динамическая аура
├── MainWindow.xaml.cs        # Основной контроллер логики и диспетчер событий
└── GeminiScreenPet.csproj    # Проект .NET 10 WPF
```

## 🚀 Сборка и запуск

Требуется: [.NET 10 SDK](https://dotnet.microsoft.com/) на Windows 10/11.

```bash
# Клонировать репозиторий
git clone https://github.com/abemesupermeme-star/gemini-screen-pet.git

# Перейти в папку
cd gemini-screen-pet

# Собрать и запустить
dotnet run
```
